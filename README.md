# Data Visualization App

Простое приложение для визуализации и анализа данных из Excel файлов, созданное с использованием PyQt6.

## Описание

Приложение позволяет загружать Excel файлы, просматривать статистику данных и строить различные графики:

- 📊 **Статистика** - основная информация о данных
- 🔗 **Корреляции** - scatter plot с линией тренда
- 🎨 **Тепловая карта** - матрица корреляций
- 📈 **Линейные графики** - визуализация временных рядов
- 📝 **Ход работы** - лог всех действий

## Технологии

- **PyQt6 6.10.0** - графический интерфейс
- **pandas 2.3.0** - работа с данными
- **matplotlib 3.10.3** - построение графиков
- **numpy 2.3.1** - математические операции
- **seaborn** - улучшенная визуализация
- **SQLite** - хранение данных

## Установка и запуск

1. Убедитесь, что установлен Python 3.8+
2. Установите зависимости:
```bash
pip install pyqt6 pandas matplotlib seaborn numpy openpyxl
3.	Запустите приложение:
bash
python main.py
Как использовать
1.	Нажмите "Загрузить Excel файл" и выберите файл (.xlsx или .xls)
2.	Данные автоматически загрузятся в SQLite базу
3.	Переключайтесь между вкладками для анализа данных
4.	Стройте графики, выбирая таблицы и столбцы
5.	Просматривайте статистику в реальном времени
Особенности
•	Многопоточная загрузка данных без зависания интерфейса
•	Автоматическое определение типов данных
•	Поддержка нескольких листов Excel
•	Интуитивно понятный интерфейс
•	Подробный лог всех операций
